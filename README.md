# gh-pixel-editor

Static pixel-art sprite editor for GitHub Actions log art ([quest-ops](https://github.com/lowlydba/quest-ops) sprite format v1). Vanilla JS/HTML/CSS, no build step, no runtime dependencies.

GitHub's log viewer paints a background over the whole line but a glyph over a shorter box, so two-colour half-block cells smear. The **Solid** preview shows a sprite under the CI constraint (one colour per text cell, `▀` with fg = bg); **Half** shows the terminal result; the smear preview models the log viewer.

## Use

```
npm run serve      # http://127.0.0.1:8080/ (serves ./site)
npm test           # node:test, no dependencies
```

Tools: pencil `P`, erase `E`, fill `F`, pick `I`, mirror-draw `M`, undo/redo `Ctrl+Z`/`Ctrl+Y`. Import/export sprite JSON, export SVG, copy ANSI (256-colour escapes only).

Deploys `site/` to GitHub Pages via `.github/workflows/pages.yml`.

## Spec

`site/spec/` is a vendored copy of the quest-ops sprite spec, schema and examples. Nothing is fetched at runtime. `site/spec/SOURCE.json` pins it:

- base commit `edffb26f79ae283a9118a256a3dc458e3a7cba04` of `lowlydba/quest-ops`
- **the spec files were uncommitted** on branch `lowlydba-sprite-format-spec` when synced, so the SHA alone does not identify them; the per-file SHA-256 hashes in `SOURCE.json` do (checked by `npm test`)

Re-sync: `npm run sync-spec -- <quest-ops-path> [<git-checkout-for-sha>]`, then update the pin note above.

`site/js/validate.js` is a hand-written port of the schema (no validator dependency); a test guards its key constants against the vendored schema.

## Conformance: parity unverified

`fixtures/` holds output for the `slime` example (base and every tier) per target: `solid`, `half`, `plain`, `svg`. They are generated by this editor (`npm run fixtures`), so they only catch regressions. They are **not** the Python renderer's output. Replace them with quest-ops reference output when available.

Choices the spec leaves open, all unverified against the reference renderer:

- `plain`: one glyph per pixel; `M` renders as a space; ramp levels map to `░░▒▒▓█` by `round(level*5/(n-1))`.
- `solid`: a tie within the same kind keeps the top pixel.
- `half`: a cell with only a bottom pixel uses `▄` (fg = bottom, no bg).
- ANSI run-merging and the `ESC[0m` placement.
- GitHub log line height and glyph aspect ratio are **unmeasured**; the preview geometry (cell width, line height, glyph/line ratio) is configurable and its defaults are guesses.
