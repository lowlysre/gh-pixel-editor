Sprite editor

Pick a colour and draw. When the sprite looks right, use Export → ANSI for GitHub logs and cat the file in a workflow step. The tutorial walks through it.

Colours and the legend

Every pixel is a legend character mapped to a colour. Picking a palette colour reuses or adds an entry for you. Click a legend character to paint with it, for example the shaded body B. To recolour an entry everywhere, pick a palette colour, then click the entry's swatch.
